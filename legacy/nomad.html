Global Platform Access SUPERADMIN ONLY

These are the ceiling settings. If you force something ON here, server admins cannot override it. If you turn something OFF globally, server admins can still turn it ON for their own server.

Force Require Code (All Servers)
When ON — every server requires monthly code regardless of their own settings.
Force Require Discord Role (All Servers)
When ON — every server requires Discord role check regardless of their own settings.
Allow Server Admins to Override
When OFF — server admins can't change their own access requirements at all.
Open Access Mode (Override All)
When ON — anyone with just a Discord username gets in. All code and role checks skipped platform-wide. Use for scaling / free access periods.
Per Server Access Settings

Override access settings for individual servers. Global settings above take priority — a lock icon means the global setting is forcing that toggle.
